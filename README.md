# FreeWay — карта доступності

Карта доступності громадських місць для людей з інвалідністю, маломобільних груп та батьків з дитячими візками.

## Опис проєкту

FreeWay — це інтерактивна карта, яка допомагає знаходити доступні місця та прокладати маршрути з урахуванням потреб людей з обмеженими фізичними можливостями.

## Предметна область

Проєкт спрямований на вирішення проблеми доступності громадських місць в Україні.

## Заплановані можливості

| Функція | Опис |
|---------|------|
| 🟢🟡🔴 Кольорові позначки | Візуальна система оцінки доступності |
|  Інтерактивна карта | Перегляд місць на карті з фільтрацією |
|  Пошук туалету | Автоматичний пошук найближчого доступного туалету |
|  Відгуки та фото | Зворотний зв'язок від користувачів |
|  Інформація про заклад | Години роботи, контакти, сайт |
|  Поділитися | Надсилання інформації про місце |

## Передбачувані сутності даних

- **Place** — місце (назва, адреса, координати, рівень доступності, пандус, ліфт, туалет, години роботи, сайт)
- **Review** — відгук (автор, оцінка, коментар, фото, дата)
- **User** — користувач (email, пароль, роль) — *планується*
