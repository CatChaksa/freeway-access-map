# 🌍 FreeWay — карта доступності

**FreeWay** — це вебзастосунок, який допомагає знаходити доступні громадські місця для людей з інвалідністю, маломобільних груп населення та батьків з дитячими візками. Проєкт покликаний зробити міста України комфортнішими для всіх.

## 📖 Опис проєкту

Основна ідея — створити єдиний інформаційний простір, де користувач може переглянути рівень доступності закладу (наявність пандусів, ліфтів, доступних туалетів) та побачити його розташування на інтерактивній карті. 

Проєкт розробляється в межах наскрізної практики з вебпрограмування та поступово доповнюється новими технологіями.

## 🎯 Предметна область та мета

В Україні досі гостро стоїть проблема відсутності єдиної бази даних про доступність закладів. FreeWay вирішує це шляхом краудсорсингу (залучення користувачів) та використання відкритих даних. 

**Цільові аудиторії:**
- Люди з інвалідністю (зокрема ті, хто користується візками).
- Маломобільні групи (літні люди, люди з тимчасовими травмами).
- Батьки з дитячими візками.
- Туристи та волонтери.

## 🗃️ Сутності даних

У проєкті використовуються такі основні сутності (наразі реалізовано у форматі JSON, у майбутньому — у БД):

- **Place (Місце)** — назва, адреса, координати (`lat`, `lng`), тип закладу, загальний рівень доступності, наявність пандуса, ліфта, доступного туалету, години роботи, сайт, фото.
- **Review (Відгук)** *(заплановано)* — автор, оцінка, текст коментаря, фото, дата.
- **User (Користувач)** *(заплановано)* — ім'я, email, пароль (хешований), роль (адмін/користувач).

## 🚀 Інструкція запуску (локально)

Оскільки проєкт використовує JavaScript-модулі та функцію `fetch` для завантаження даних із JSON-файлів, відкривати файл `index.html` подвійним кліком не можна. Для перегляду сайту необхідно використовувати локальний вебсервер.

- Клонуйте репозиторій: `git clone https://github.com/CatChaka/freeway-access-map.git`
- Перейдіть у папку проєкту: `cd freeway-access-map`
- Відкрийте папку у вашому редакторі коду (наприклад, у VS Code).
- Запустіть локальний сервер (оберіть один з варіантів):
  - Варіант А (найпростіший): Встановіть розширення **Live Server** у VS Code. Натисніть правою кнопкою миші на файл `index.html` та виберіть **"Open with Live Server"**.
  - Варіант Б (через термінал): Якщо у вас встановлено Node.js, виконайте команду `npx serve`. Потім перейдіть за посиланням (зазвичай `http://localhost:3000`), яке з'явиться в терміналі.
- Готово! Сайт відкриється у вашому браузері. Для перевірки коректної роботи перейдіть на вкладку «Місця» або «Карта».
