# FreeWay — карта доступності

Карта доступності громадських місць для людей з інвалідністю, маломобільних груп та батьків з дитячими візками.

## Опис проєкту

FreeWay допомагає знаходити доступні місця та прокладати маршрути з урахуванням потреб людей з обмеженими фізичними можливостями.

## Предметна область

Проєкт спрямований на вирішення проблеми доступності громадських місць в Україні.

## Заплановані можливості

- 🟢🟡🔴 Кольорові позначки доступності
-  Інтерактивна карта
-  Пошук найближчого доступного туалету
-  Відгуки та фото від користувачів
-  Інформація про заклад (години, сайт)
-  Поділитися місцем з друзями
